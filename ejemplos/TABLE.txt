{ **************************************************

   Glass table with vase and candy bowl.  This
   is the first test of glass surfaces, and came out

   glass!  This image requires QRT 1.4 to run.

   Rendered with QRT rayracing system

   Steve Koren -  23 AUG 88

  ************************************************** }
